**場景設定**
假設有一堆手寫數字的圖片，組成一條條算式，例如：
```
[圖A] + [圖B] = [圖C][圖D]
```
> [!abstract] 論文重點
> 神經網路負責「看」（例如辨識手寫數字圖片），符號規則負責「想」（例如做加法）。但現有的做法太依賴標註資料——就算不標每張圖是幾，至少也要告訴系統「這兩張圖加起來等於 17」。這種標註在真實場景常常拿不到。
> 
> 如果不給標籤？作者指出這會同時引爆三個問題：可用的資訊變少、解空間變得很大、而且「抄捷徑」的假解暴增。舉例來說，若已知答案是 17，唯一的捷徑解是 8+9；但如果連答案都不知道，那 0+0=00 這種也「符合加法規則」，捷徑就多到無法收斂。
> 
> **它的解法:** 把「拿標籤對答案」換成「拿一個驗證函數檢查預測有沒有違反規則」
> 神經網路猜圖片是什麼數字，符號系統檢查這些猜測湊起來是否正確。他們把這件事寫成一個約束最佳化問題，並提出 Dynamic Combinatorial Sorting 演算法來減少驗證嘗試次數、壓低運算成本，另外用先驗對齊（prior alignment）來擋掉捷徑。並從理論上分析了哪些任務成功、為什麼規則在某些任務能取代無限多標籤、某些任務卻完全沒用。實驗涵蓋加法、排序、配對、西洋棋四個全無監督任務。
## 約束最佳化
「最佳化問題」：在很多可能的選項裡，挑出一個讓某個指標最好的答案。
加上「約束」，就是這些選項還必須滿足一些硬規定，不合規的直接不算。
## 序理論（order theory）與組合最佳化: 保證順序的函數
- **independence assumption** — 獨立性假設
	- Variable 間沒有交互作用，總分就是各 Variable 好壞的合成
- **monotonicity** — 單調性
	- 把某個位置從第 q 名換成第 q+1 名，總分不會上升——而且這件事在其他位置任意取值時都成立
