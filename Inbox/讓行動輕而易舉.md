 # Why 行動重要?
## 啟動 ≠ 行動
> 啟動能讓我們感覺有所進展, 卻不必冒失敗風險
## 要精通一項習慣，關鍵是 "重複行動"
`每次行動都強化了相關細胞間的連結信號傳遞`
> 重點是重複做了幾次(頻率)，不是做了多久
> ![[Pasted image 20260311000753.png]]

# 最小努力原則
大腦設計: 盡可能節省能源。
人類比較容易選擇花費較少力氣的選項
> 讓習慣簡單到就算沒有意願也會執行
## 創造出一個讓正確事情盡可能輕而易舉的環境
~~~
減少與好習慣相關的阻力，增加與壞習慣相關的麻煩
~~~
+ **減少阻力(培養好習慣):** 事先做好一些準備，讓下一次的使用輕而易舉
+ **增加阻力(戒掉壞習慣):** 把過程變複雜 (`ex. 手機放別的房間, 拔掉電視插頭`)

## 專注在前兩分鐘改善拖延
>[! 理論基礎]
>+ **決定性瞬間:** 決定如何運用接下來的一段時間
>	+  `幾個決定性瞬間，一整天的就會過得很不同`
>+ **習慣是起點不是終點:** 一個習慣可以在幾秒內完成，卻能形塑幾分鐘甚至幾小時後的行為

>==**兩分鐘法則**: 新習慣的開始應該要花不到 2 mins==

+ 引導在決定性瞬間做出對的選擇 `讓習慣容易開始，其他的自然會展開`
+ 變成開啟後續行動的儀式
+ 強化身分認同
>**習慣塑造:**每個階段都先專注在 2 mins最簡版本習慣(行動開始的儀式)
```
運動習慣養成階段:
1. 換上運動服(最簡版本 2 min)
2. 踏出家門
3. 去健身房，運動5min
4. 運動15min
```
