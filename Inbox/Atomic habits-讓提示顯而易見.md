# 指差確認:察覺習慣
 對自己的行為保持意識&覺察, 是改變習慣最大的挑戰之一
 ~~~
指差確認:源自日本鐵路司機，手指物體，嘴巴喊出指令。
 ~~~
===透過開口說出自己的行為，把無意識的習慣拉到有意識的層次===
+ 說出壞習慣+導致結果: 會讓後果更加真實, 避免無意識地重拾舊習
+ 說出預計執行的好習慣: 讓自己承認行動的必要, 可以提高實際去做的機率
## 習慣計分卡
覺察現有習慣，並標記**有效習慣**:`對渴望的身分認同投下同意票`
# 開始新習慣的最好方法
> 關鍵: 確保提示的出現並且提示內容越明確越好
## 執行意向: 先規劃好執行的==時間==&==地點==
因為清晰提示非always顯而易見，因此先設計好`你打算如何執行這個習慣?`
> 時間 + 地點 就是觸發行動的明確提示。

```
我會於(時間),在(地點)進行(行為)
```
## 習慣堆疊: 用前一個習慣做為提示
```
狄德羅效應(行為的連結性): 買了地毯就想添購其他家具來升級整個客廳
```
把新習慣跟現有的習慣綁在一起，就習慣的內容描述越明確越好
+ X: 中午休息時, 做十下push-ups
+ O: 闔上電腦, 吃午餐前, 在書桌旁做十下push-ups

```
做完(目前的習慣)之後,我會執行(新的習慣)
```
