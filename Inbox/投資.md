# 財務資本取代人力資本
+ EX.人力資本與財務資本互換
	一年賺50,000, 還能工作40年, 總未來所得200萬
	if [[折現率]]3%, then 人力資本現值120萬
	如果現在把120萬拿去投資，年報酬3%，未來40年每年可領50,000而不把錢花光
