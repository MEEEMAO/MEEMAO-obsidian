>讓好習慣顯而易見 讓壞習慣隱而不見

大腦會分析環境 標記提示 以供未來使用
無意識的注意到提示 並激起行動的渴望 就是習慣的基礎
~~~
激發習慣的提示變得太過尋常，基本上隱形了
~~~
榮格: 倘若無法意識到無意識，他就會指揮你的生活，然後你會稱之為命運
# 指差確認:察覺習慣
 對自己的行為保持意識&覺察, 
 ~~~
指差確認:源自日本鐵路司機，手指物體，嘴巴喊出指令。
 ~~~
===透過開口說出自己的行為，把無意識的習慣拉到有意識的層次===
+ 說出壞習慣+導致結果: 會讓後果更加真實, 避免無意識地重拾舊習
+ 說出預計執行的好習慣: 讓自己承認行動的必要, 可以提高實際去做的機率
## 習慣計分卡
覺察現有習慣，並標記**有效習慣**:`對渴望的身分認同投下同意票`
# 開始新習慣的最好方法
> 關鍵: 確保提示的出現並且提示內容越明確越好
## 執行意向: 先規劃好執行的==時間==&==地點==
因為清晰提示非always顯而易見，因此先設計好`你打算如何執行這個習慣?`
> 時間 + 地點 就是觸發行動的明確提示。

```
我會於(時間),在(地點)進行(行為)
```
## 習慣堆疊: 用前一個習慣做為提示
```
狄德羅效應(行為的連結性): 買了地毯就想添購其他家具來升級整個客廳
```
把新習慣跟現有的習慣綁在一起，就習慣的內容描述越明確越好
+ X: 中午休息時, 做十下push-ups
+ O: 闔上電腦, 吃午餐前, 在書桌旁做十下push-ups

```
做完(目前的習慣)之後,我會執行(新的習慣)
```

# 環境設計-情境is提示
> 要讓行為變的穩定且可預測 就需要穩定且可預測的環境

+ 重新設計環境 並讓觸發你想要的習慣的提示更為明顯
	`要看的書放在桌上之類的`
+ 新習慣跟新情境連結在一起比較容易 因為就不用對抗舊習慣
+ 如果無法換環境, 重新定義或整理當前環境
	+ 一個空間一個用途 `閱讀專用椅` or `寫作專用桌`
+ 自制力: "自律者"只是擅長建構生活, 讓自己不需要展現超凡意志力與自我控制力
+ 意志力無法每次都戰勝慾望 最好的方法就是減少觸發惡習的提示
