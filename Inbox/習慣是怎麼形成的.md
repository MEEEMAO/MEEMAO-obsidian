> 每個習慣的目的都是要解決遇到的問題
> ex. 注意到好東西想要得到它 or 經歷痛苦想要解除

>大腦減輕認知負擔: 針對規律問題的自動化解決方案

~~~
帶來可喜後果的行為往往會被重複 帶來可厭後果的行為比較不可能被重複
~~~
## 習慣形成: 回饋迴路
### 問題階段
+ 1. [[讓提示顯而易見|提示]]: 預示可能會有獎賞的資訊
	+ 人會自動在環境中搜尋提示以尋找獎賞
+ 2. 渴望: 提示會引發渴望
	+ 根據觀察者的思想&感覺&情緒不同, 會決定提示是否能誘發渴望 
### 解決方案階段
+ 3. 回應: 渴望引起回應
	+ 回應是否發生, 取決於受多少刺激 & 行動的阻力大小  
+ 4. 獎賞: 回應帶來獎賞
	+ 習慣的終極目標
	+ 目的1: 滿足渴望
	+ 目的2: 要記住哪些行為
## 行為改變法則
### 建立好習慣:
+ 提示: 讓提示顯而易見
+ 渴望: 讓習慣有吸引力
+ 回應: 讓行動輕而易舉
+ 獎賞: 讓獎賞令人滿足
### 戒掉壞習慣:
+ 提示: 讓提示隱而不見
+ : 讓習慣毫無吸引力
+ 回應: 讓行動困難
+ 獎賞: 讓獎賞令人不滿
