> [!abstract] 透過指差確認察覺無意識習慣，用執行意向、習慣堆疊、環境設計讓好習慣的提示明確可見

> 讓好習慣顯而易見，讓壞習慣隱而不見

大腦會分析環境、標記提示以供未來使用。激發習慣的提示變得太過尋常，基本上隱形了。

## 指差確認：察覺習慣

===透過開口說出自己的行為，把無意識的習慣拉到有意識的層次===

- 說出壞習慣 + 導致結果：讓後果更加真實，避免無意識重拾舊習
- 說出預計執行的好習慣：承認行動的必要，提高實際去做的機率

**習慣計分卡**：覺察現有習慣，標記「對渴望的身分認同投下同意票」的有效習慣

## 執行意向：規劃好時間與地點

> 關鍵：確保提示的出現，且提示內容越明確越好

```
我會於（時間），在（地點）進行（行為）
```

## 習慣堆疊：用前一個習慣做為提示

> 狄德羅效應（行為的連結性）：買了地毯就想添購其他家具來升級整個客廳

```
做完（目前的習慣）之後，我會執行（新的習慣）
```

習慣的內容描述越明確越好：
- ✗ 中午休息時做十下 push-ups
- ✓ 闔上電腦、吃午餐前，在書桌旁做十下 push-ups

## 環境設計：情境就是提示

> 要讓行為變得穩定且可預測，就需要穩定且可預測的環境

- 重新設計環境，讓觸發好習慣的提示更為明顯
- 新習慣跟新情境連結比較容易（不用對抗舊習慣）
- 一個空間一個用途（閱讀專用椅、寫作專用桌）
- 自制力：「自律者」只是擅長建構生活，不需要展現超凡意志力
- ==最好的方法就是減少觸發惡習的提示==
