> [!abstract] 台股正常交易時段採逐筆即時撮合，零股與盤後則採集合競價，新手最適合「限價 + ROD」

## 交易時段總覽

```
08:30        09:00                    13:25  13:30  13:40       14:00  14:30
  |            |                        |      |      |            |      |
 開始          正式開盤                  切換   收盤    盤後          盤後    統一
 接受          逐筆撮合                  集合   整股    零股          定價    撮合
 委託          (即時成交）               競價   結束    開始          交易    結束
```

| 時段           | 時間          | 成交方式              | 說明                            |
| :----------- | :---------- | :---------------- | :---------------------------- |
| **一般交易（整股）** | 09:00–13:30 | 逐筆即時撮合            | 每筆委託即時配對成交，股價即時跳動             |
| **盤中零股**     | 09:00–13:30 | ==每 5 秒集合競價撮合一次== | 2024/12 起由每分鐘縮短為 5 秒，首筆 09:10 |
| **盤後零股**     | 13:40–14:30 | 14:30 統一撮合一次      | 以**當日收盤價**成交，掛漲停價可提高成交機率      |
| **盤後定價交易**   | 14:00–14:30 | 14:30 統一撮合一次      | 整張（1,000 股）交易，也是以收盤價成交        |

## 交易單位

- **整股**：1 張 = 1,000 股（金額較大）
- **零股**：1 股起買（適合小資族）

## 每日漲跌幅

每天最多漲跌 **±10%**。例：股價 100 元 → 漲停 110 元 / 跌停 90 元。

## 委託方式

| 維度     | 類型        | 說明                |
| :----- | :-------- | :---------------- |
| **價格** | 限價        | 自己設定價格，未達到不成交     |
|        | 市價        | 馬上以市場價成交，可能買貴     |
| **存續** | ROD（當日有效） | 今天未成交自動取消，==最常用== |
|        | IOC       | 部分成交即可，剩餘取消       |
|        | FOK       | 全部成交否則全部取消        |

> [!tip] 新手建議
> **限價 + ROD** 最安全直覺——設好心理價位，當天沒成交就自動取消。
