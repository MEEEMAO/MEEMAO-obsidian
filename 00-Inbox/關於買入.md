# 現在買 or 分批買？
> 結論: 風險較低組合(ex. 股6債4)一次買進
+ 唯有股市中大崩盤前, 平均投資策略的績效才會顯著優於現在買(1929, 2008年)
![[Pasted image 20260508233848.png|center|621]]
- 美股單月一次投入, 選到績效劣於平均投入的月份的機會 30%
![[Pasted image 20260508234054.png|center|631]]
+ 一次投入的風險 > 分批買進 (標準差)
![[Pasted image 20260513111838.png|center|511]]
+ 但如果改採一次買進＋較低風險投資組合 => 較低風險&不錯績效
```
雖然 “股6債4現在買”績效超額不如“100%股現在買”, 但風險可以和 “100%股平均買進”差不多
```

# 該擇時等低點再買? 分批買 vs 逢低買進
> 分批買: 一個月100 
> 逢低買: 假設知道所有低點位置(累積到兩個歷史高點間的最低點買)
```
70%時間, 分批買勝; 
就算可以知道最低點位置,也要發生在投資早期(1930熊市);
一直等待低點, 錯過牛市持續上漲
```

# 可接受的波動性？避開多大的波動才會使財富最大化？
> 15% (接受0-15%的波動下跌, 盡量避開15%以上的年內下跌)

```
年內最大跌幅（Maximum Drawdown within the year): (年內最高-年內最低) / 年內最高
```
